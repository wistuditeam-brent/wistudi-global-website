About the workshop

Build the lesson around what students need to do next

Teachers have access to countless tools and activities, but choosing something simply because it is engaging does not automatically make it useful for learning. This workshop focuses on the purpose behind each activity and how those choices fit together across a lesson.

We’ll work through a complete communicative ESL lesson and look at how learners can move from becoming familiar with language to using it more independently.

You’ll consider what students need at each stage, how much support is appropriate, and why the same activity can be effective in one part of a lesson but less useful in another. We’ll also compare alternative activities that can achieve the same learning purpose, so the focus stays on the learner rather than on any one tool.

The workshop includes a complete lesson built in Wistudi Flow. You’ll see how different activity types can support each stage of the journey, then look at how the same lesson can be adapted for offline teaching and exported as a printable worksheet.

Whether you teach online, in person, or across both, the central question remains the same: how do we create a learning journey that steadily helps students move toward meaningful communication?

Choose activities with intention

Look beyond whether an activity is fun and consider the learning job it needs to do.

Move from support to independence

Explore how scaffolding can change as learners become more confident using language.

Compare different routes

Brainstorm alternative activities that can achieve the same communicative purpose.

Connect digital and printable teaching

See how one lesson can move between interactive delivery and an offline worksheet.
