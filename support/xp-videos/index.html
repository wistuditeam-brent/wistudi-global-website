Creating & publishing

Create an XP Video

Add a video, place activity checkpoints, configure the learner experience and prepare your XP Video for publishing.

Wistudi Support · Updated 18 November 2026
Quick answer

Add a source video to your workspace, choose Create Interactive Lesson or Make Interactive, then use Add Activity Checkpoint at the moment you want learners to respond.

Start with the learning purpose

Choose a video that supports one clear learning goal. Decide where a learner needs to do something with what they have watched: recall a detail, make a choice, sort examples or explain an idea.

Put a checkpoint near the relevant moment rather than collecting every question at the end. For example, pause a demonstration after a key step and ask learners to identify what should happen next.

Use only videos you own or have permission to use. An external video remains dependent on its source and embedding permissions.

Add your video

  1. Sign in and open the XP Video Workspace in your publishing area.
  2. Choose Upload Video to open the Add Video flow.
  3. Choose Upload Video for a file, or External URL for a supported YouTube or Vimeo link.
  4. Follow the upload or Fetch Video Details steps. Review the required title, category, topic and other fields shown.
  5. Save the source video, then choose Create Interactive Lesson. For a source already in your workspace, use Make Interactive where offered.

A saved source video is not automatically an interactive lesson. You still need to add and configure the activities. See Videos, uploads and resources if the source cannot be added.

Add and configure checkpoints

  1. Play or seek to the relevant timestamp in the video.
  2. Choose Add Activity Checkpoint and select an available activity type.
  3. Write the prompt and any learner instructions. Add the questions, options or activity items required by that type.
  4. Set the correct answers and relevant feedback or grading options.
  5. Save the activity and repeat at other learning moments.

If an activity already exists at the timestamp, select that checkpoint to work on it. Do not add an empty checkpoint as a placeholder and expect it to pass publication checks.

Choose each activity for its purpose. A quick question checks understanding; sorting or matching asks learners to apply a relationship; a written response needs a clear prompt and, when graded, a marking approach.

Review playback and assessment settings

Open Activity Playback Settings and review the controls available for progression, navigation, attempts, retakes and the video pass mark. Check the Lesson Rules summary to see how these choices affect the learner.

Sequential learning asks learners to complete activities in order and can restrict skipping ahead. Open navigation and retake choices change how learners practise. Use the settings displayed in the current interface rather than assuming every activity has independent controls.

Preview, save and publish

Use Preview Learner View once the lesson has enough complete content to preview. Check checkpoint timing, instructions, answers and the route back to playback. Preview is for checking the experience; share a learner link for actual participation.

Use Save Draft and confirm that the save succeeded. If saving is disabled, read the message about empty activities, missing prompts or incomplete questions.

Review Publishing Requirements before choosing Publish. Requirements can vary with video length, and all activities must be configured. Review any credit confirmation before proceeding. After publication succeeds, use Share to obtain learner access.
