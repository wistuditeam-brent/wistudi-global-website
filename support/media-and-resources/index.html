Creating & publishing

Videos, uploads and resources

Add uploaded files and supported external video links, preserve attribution, and resolve media or resource problems.

Wistudi Support · Updated 18 November 2026
Quick answer

Use the supported upload or external-link option, review the file or source details and test the resource in preview. External media must remain available at its original source.

Choose an upload or an external video

In the video-adding flow, Upload Video adds a file from your device. External URL adds an individual video from a supported source such as YouTube or Vimeo.

Use an upload when you have a suitable file and the rights to publish it. Use an external URL when you want to use an eligible video hosted by the source platform. Adding a link does not transfer ownership of that video or guarantee that it will always remain available.

Upload a video file

  1. Open the video-adding flow from your workspace and choose Upload Video.
  2. Select Choose File or use the drop area.
  3. Follow the formats and size limit displayed for your account. MP4 and WebM are supported upload options; if your file is rejected, follow the specific validation message.
  4. Wait for the upload to finish before continuing.
  5. Review the title, description, category, topic and other required details.
  6. Save the video and check the success message before closing the flow.

Changing a file extension does not convert its format. If a MOV or another unsupported file is rejected, export or convert a separate copy into a supported format and keep your original file.

Upload limits can depend on the current account configuration. Use the limit shown in the uploader rather than relying on a limit quoted in an older guide.

Add a YouTube or Vimeo link

  1. Choose External URL and select the source platform.
  2. Paste the complete video URL into the matching field.
  3. Choose Fetch Video Details.
  4. Review the retrieved video and complete the remaining required classification fields.
  5. Save, then preview the video before adding or publishing learning around it.

For external sources, the title, description and thumbnail can be supplied by the source platform and locked against editing. Preserve the source attribution and channel or original-video links shown by Wistudi.

Do not use an unauthorised downloaded copy to work around embedding restrictions. A video that is private, removed, region-restricted or unavailable for embedding may not play for your learners.

Add supporting media and resources

Use the content or resource controls available in the selected Flow block or activity to add images, video, PDFs or links. The options depend on the block; not every activity accepts every type of attachment.

Use descriptive names and captions so learners know why a resource matters. Make sure the text in an image or PDF remains readable at the size learners will see.

Check the permission settings of external documents separately. A resource being visible to you while signed in to its source service does not prove that learners can open it. Test the learner link and arrange appropriate access with the resource owner.

If media does not work

  • Upload rejected: check the actual file format and the account limit shown.
  • Details cannot be fetched: check the selected platform and complete URL.
  • Video plays for you but not learners: check the source's visibility, embedding and regional restrictions.
  • Resource asks for permission: review the permissions at the external service.
  • Preview shows the wrong file: check that you selected the intended page or block before replacing anything.

If the problem continues, contact support with the content title, affected resource and exact message. Do not send private learner work or credentials unless specifically needed through an authorised support route.
