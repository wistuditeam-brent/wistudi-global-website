Creating & publishing

Blocks and activities

Choose blocks for a learning goal, configure the learner task and check answers, feedback and grading before publication.

Wistudi Support · Updated 18 November 2026
Quick answer

Choose a block for what the learner needs to do, then configure the prompt, response and assessment. Preview the interaction before publishing it.

Choose by learning purpose

Start with the learner's action, not the longest feature list. A block is useful when it helps someone understand, practise, explain or demonstrate something.

  • Explain or demonstrate: use text, images, video or a supporting document.
  • Check a specific answer: consider Multiple Choice, True / False or Picture Quiz.
  • Connect ideas: use Link & Match for pairs and relationships.
  • Classify examples: use Smart Sorting when learners need to distinguish categories.
  • Order a process: use Sequence & Reorder when order is the learning goal.
  • Explain thinking: use Written Response or a reflection activity with a clear prompt.
  • Collect a view: use Community Poll when you want a response or discussion starter rather than a single correct answer.

The block menu is the source of available choices. Some blocks belong to a particular builder or can be unavailable for your account. A block marked Coming soon is not ready to add.

Add the block in the right place

In a Flow, select the page you are editing and open its block-adding controls. In an XP Video, select a timestamp, choose Add Activity Checkpoint and select an available activity.

Place the task close to the explanation or media it depends on. If a block depends on information from a previous page or video section, make that connection clear in the instructions.

Configure the task completely

  1. Write a prompt that tells learners what to do and what information to use.
  2. Add the items needed by the activity: answer options, category labels, matching pairs, ordered items or a response prompt.
  3. Set the correct answers or intended order where the block uses automatic checking.
  4. Check image readability, captions and any supporting resources.
  5. Review the feedback and response settings available for that block.
  6. Save and resolve any missing-content warnings.

A short instruction such as “Match each term to its meaning” is more useful than a decorative title with no task. Keep prompts understandable without the teacher needing to explain the interface separately.

Decide how the response is assessed

Separate practising from being assessed. Review the block's available grading controls and any overall lesson rules before deciding what should affect a result.

For automatically checked activities, verify the answer configuration. For a graded written response, provide an appropriate marking guide and points using the controls offered. A poll should not be presented as a knowledge test unless the activity actually supports that assessment.

Settings can operate at different levels. XP Video attempt and progression rules may be controlled in the video settings, while a block can have its own response or feedback options. Do not assume a field on one block exists on every other block.

Test before publishing

Preview the activity as a learner. Try the expected response and a plausible mistake. Check whether feedback appears when intended and whether the learner can continue, retry or submit as the lesson requires.

For manual responses, check that instructions and assessment criteria agree. If a supporting file is required, make that requirement clear before the learner starts.

If a block is unavailable or publication is blocked, read the specific requirement in the builder. Some eligible actions or advanced options can depend on credits; review the confirmation shown rather than assuming all blocks have the same publishing treatment.
