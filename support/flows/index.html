Creating & publishing

Create a Flow

Build a learning sequence with pages, collections, content and activities, then configure, preview and publish it.

Wistudi Support · Updated 18 November 2026
Quick answer

Open Flow Workspace, choose New Flow, select an available starting structure and build your learning sequence with pages and blocks. Complete Flow Settings before publishing.

Outline the learning sequence

A Flow brings explanations, media, activities and assessment into one learning experience. Start with what learners should understand or be able to do, then sketch the steps that will help them get there.

A short sequence might introduce the topic, show an example, ask learners to practise and finish with reflection. Use collections when a larger experience needs clear groups of pages.

Create the Flow in your workspace

  1. Sign in and open Flow Workspace.
  2. Choose New Flow or the Create Flow action in an empty workspace.
  3. Enter a descriptive Flow Name and complete the category and topic fields shown.
  4. Review Choose Your Starting Structure and select an available option.
  5. Continue with the creation action shown to open your Flow.

Single Flow describes pages directly inside the Flow. Structured Flow organises content using collections and pages. A choice marked as unavailable or coming soon cannot be used yet; select an available structure. Choose the organisation you need before building a large amount of content.

Organise pages and collections

Use the structure navigation and Add New Content controls to add the pages or collections supported by your Flow. Add Page creates a page under the selected Flow or collection; Add Collection creates a grouping within the Flow.

  1. Name each page for its learning purpose.
  2. Select the page you want to edit before adding content.
  3. Arrange the pages in a useful learning order.
  4. Keep related pages together in a collection when the structure supports it.

Workspace collections used to organise your library are different from collections inside a Flow's learning structure. Moving a Flow into a workspace collection does not build its internal sequence.

Build the pages with blocks

Add content blocks for explanation and examples, then activity blocks for the learner's response. Set the instructions, media, answers and grading options available for each block.

A page should have a clear purpose. Avoid squeezing unrelated activities together just to reduce page count. Check the page layout and any space or placement warnings in the builder.

For example, use a short explanation and example to introduce a concept, then a sorting activity to check how learners classify new examples. See Blocks and activities for guidance on choosing interactions.

Complete Flow Settings

Open Configure Flow or Flow Settings. Review the required fields under General Info, Content & Identity and Visuals & Branding.

Use a clear description, learning outcomes, appropriate trainer information and representative visuals. Follow any remaining required-settings messages, then choose Save & Exit.

If you use an AI-assisted fill action, review its output before saving. You are responsible for the accuracy of descriptions, outcomes and images.

Preview and prepare to release

Preview the learner experience from the builder. Read it in order and try the activities, including incorrect answers where appropriate. Check that instructions, media and completion requirements make sense together.

Save your draft and review the publishing confirmation. Workspace publication and a public Discover listing are separate states: a workspace version can be published while a Discover submission is still under review.

Read Publish, update and manage versions before releasing the Flow, then use the learner sharing controls when access is ready.
