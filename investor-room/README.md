# Wistudi Investor Room

Private investor-facing presentation page architecture.

## Structure

- `index.html` — investor room page (to be built)
- `assets/presentation/` — investor presentation PDF
- `assets/images/` — investor-room-only imagery if needed
- `assets/js/` — page-specific scripts if separated later
- `assets/css/` — page-specific styles if separated later

The investor page will remain off the public navigation and should not be added to sitemap.xml.

Planned page flow:
1. Password/access gate
2. Investor presentation viewer
3. Investor snapshot
4. Wistudi product video
5. Growth/compounding visual
6. Contact + Calendly booking
